# COASTLINE — Фестиваль Побережья

Гоночная игра с открытым миром в духе Forza Horizon, написанная на C++20 с [raylib 5.5](https://www.raylib.com/). Действие происходит на вымышленном острове. Там проходит автомобильный фестиваль: на побережье, в горах, в городке, в лесу и на пляжах стоят гонки, радары, зоны скорости и трамплины. Остров размером около 3 × 3 км собирается при запуске, и между всеми точками можно проехать без загрузок.

Все модели, текстуры, звуки и музыка генерируются кодом: в проекте нет ни одного графического или звукового файла, только два шрифта с лицензией OFL. Игра собирается в нативное приложение (Windows, Linux, macOS) и в WebAssembly для браузера.

## Что есть в игре

- **Открытый мир.** Рельеф с горным массивом, реками, бродами и озером. Прибрежное шоссе вокруг острова и серпантин на Орлиный пик. Городок Порто-Бриз с кварталами и фонарями, аэродром, маяк, ветряки, обсерватория, фермы и пляжи. Фестивальная площадка со сценой, экранами, трибунами, шатрами и публикой. Около 25 тысяч деревьев.
- **Смена суток.** Солнце и луна движутся по небу, освещение и туман меняются, над фестивалем летают воздушные шары. На небе облака и звёзды. Ночью горят фонари, окна домов, фары и огни сцены, а маяк вращает луч.
- **Физика машин.** Твёрдое тело на частоте 120 Гц, лучевая подвеска со стабилизаторами, шины с комбинированным скольжением, двигатель с кривой момента, сцепление и коробка передач. Есть аэродинамика с прижимной силой, вода с сопротивлением и всплытием, столкновения и разрушаемые объекты.
- **Помощники.** АБС, антипробуксовка, стабилизация, помощь рулению и автоматическая коробка отключаются в настройках.
- **14 машин.** Хэтчбек, маслкар, раллийная машина, родстер, универсал, классика, GT, японский спорткар, внедорожник, багги, суперкар, трековый болид, электрокар и гиперкар. У каждой свой индекс производительности (PI) и класс от D до X.
- **14 событий.** Шоссейные гонки, грунтовые, кросс-кантри по бездорожью и дрэг на взлётной полосе. Финальное шоу — гонка против пилотажного самолёта. В каждом событии до 7 соперников под управлением ИИ.
- **18 трюков.** Радары, зоны скорости, дрифт-зоны и прыжки с трамплинов. За каждый дают до трёх звёзд.
- **Цепочка навыков.** Дрифт, полёт, высокая скорость, разрушения и обгоны складываются в цепочку с множителем. Если врезаться, цепочка сгорит.
- **30 досок опыта** спрятаны у дорог.
- **Прогресс.** Опыт и уровни, кредиты, гараж с перекраской, автосалон и колесо удачи с кредитами и машинами.
- **Карта** с быстрым перемещением и метками.
- **Перемотка времени.** Можно отмотать до 10 секунд назад, в том числе в гонке.
- **Машины в свободной езде** ездят по прибрежному шоссе и лесной дороге.
- **Процедурный звук.** Мотор (у каждой машины свой тембр и число цилиндров, турбина, электромотор), визг шин, ветер, удары, звуки интерфейса и фоновая музыка.
- **Сохранение.** Прогресс хранится в файле `coastline_save.txt` рядом с игрой, а в браузере — в `localStorage`.

## Управление

| Действие | Клавиатура и мышь | Геймпад |
|---|---|---|
| Газ / тормоз и задний ход | W / S или ↑ / ↓ | RT / LT |
| Руль | A / D или ← / → | левый стик |
| Ручной тормоз | Пробел | A |
| Передача вверх / вниз (ручная коробка) | E / Q (Shift / Ctrl) | B / X |
| Перемотка (удерживать) | R или Backspace | Y |
| Сменить камеру (сзади, далеко, капот, бампер) | C | RB |
| Смотреть назад | V | LB |
| Обзор | правая кнопка мыши | правый стик |
| Начать событие у маркера | Enter | крестовина ↑ |
| Вернуться на дорогу | T | — |
| Фары | L (ночью включаются сами) | — |
| Карта | M или Tab | Back |
| Меню / пауза | Esc или P | Start |
| Помощь / отладочная информация | F1 / F3 | — |

В меню работают стрелки, Enter и Esc, вкладки переключаются клавишами Q и E. Мышь тоже работает.

## Сборка и запуск

Нужны CMake 3.20+ и компилятор с поддержкой C++20 (MSVC 2022, GCC 11+ или Clang 14+). При первой сборке CMake сам скачает raylib 5.5, поэтому нужен интернет.

### Windows, Linux, macOS

```bash
cmake -S coastline -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j
./build/coastline            # Windows: build\Release\coastline.exe
```

На Linux понадобятся пакеты для raylib: `libx11-dev libxrandr-dev libxinerama-dev libxcursor-dev libxi-dev libgl1-mesa-dev libasound2-dev`.

Готовые сборки для Windows, Linux и браузера собирает GitHub Actions ([workflow](../.github/workflows/coastline.yml)): скачайте артефакты `coastline-windows`, `coastline-linux` или `coastline-web` на странице запуска.

### Браузер (WebAssembly, WebGL 2)

Нужен [Emscripten](https://emscripten.org/docs/getting_started/downloads.html):

```bash
emcmake cmake -S coastline -B build-web -DCMAKE_BUILD_TYPE=Release
cmake --build build-web -j
python3 -m http.server 8000 -d build-web
# открыть http://localhost:8000/coastline.html
```

Страницу нужно открывать через веб-сервер: если открыть файл напрямую, браузер не загрузит `.wasm`. Звук включится после первого клика или нажатия клавиши, так требует политика браузеров.

Если добавить `-DCOASTLINE_SINGLE_FILE=ON`, получится один HTML-файл около 3 МБ: wasm встроен в него в base64. Такой файл удобно выкладывать как отдельную страницу. Оболочка для него — `web/artifact_shell.html`. Это фрагмент без `<html>` и `<head>`, поэтому для локального запуска его нужно обернуть в страницу с `<meta charset="utf-8">`.

### Тесты

```bash
ctest --test-dir build --output-on-failure
```

`coastline_tests` проверяет мир, физику и все события без окна и видеокарты:

- рельеф, дороги и уклоны;
- разгон, торможение, повороты;
- падение с высоты, удар о дерево;
- проходимость всех 14 маршрутов: автопилот доезжает до финиша, соперники тоже.

## Отладка и автоматизация

Игру можно водить скриптом. Эти же команды доступны из JavaScript в браузере через `Module.ccall('cl_cmd', 'string', ['string'], ['info'])`.

```bash
./build/coastline --fixed --nosave --script сценарий.txt   # команды по строкам
./build/coastline --cmd "event coast_sprint" --cmd "autodrive 1"
./build/coastline --size 1920x1080
```

| Команда | Что делает |
|---|---|
| `newgame [машина]` | новая игра с выбранной машиной (`lastochka`, `kaizen`, …) |
| `event id` | начать событие (`coast_sprint`, `fest_ring`, `hillclimb`, …) |
| `autodrive 1` | автопилот в гонке |
| `teleport x z [курс]`, `place id` | переместиться (`festival`, `town`, `summit`, `lighthouse`, …) |
| `car id`, `time часы`, `cam 0..3`, `quality 0..2 тени` | машина, время суток, камера, графика |
| `input газ тормоз руль ручник кадров` | принудительное управление на N кадров |
| `wait N`, `waitstate results [кадров]` | подождать кадры или нужное состояние |
| `shot файл.png`, `info`, `quit`, `autoquit` | снимок экрана, состояние в JSON, выход |

## Устройство проекта

```
coastline/
  src/core/     математика (векторы, кватернионы), шум Перлина
  src/world/    генерация острова: рельеф, реки, дороги, мосты, объекты, коллизии
  src/sim/      физика машин, каталог, маршруты, ИИ, события, навыки, профиль
  src/render/   шейдеры (GLSL 330 / ES 300), процедурные текстуры и модели,
                рельеф с LOD, дороги, вода, небо, тени, инстансинг, эффекты, камера
  src/ui/       шрифты с кириллицей, виджеты, карта
  src/audio/    синтез звука и музыки в реальном времени
  src/game/     состояния игры, HUD и меню, команды для тестов
  tests/        автотесты симуляции
  web/          HTML-оболочка для браузерной версии
```

Симуляция (`coastline_core`) не зависит от графики, поэтому тесты проходят без окна.

Рендер работает в один прямой проход с MSAA. Тональная компрессия ACES, туман и гамма-коррекция выполняются прямо в шейдерах. Тени строятся по карте глубины с PCF. Деревья рядом с камерой рисуются инстансингом, дальние — склеенными упрощёнными мешами.

## Честно об ограничениях

- **Графика** стилизованная, низкополигональная и полностью процедурная. До фотореализма Forza Horizon далеко: нет отражений в реальном времени, объёмных облаков и детализированных моделей.
- **Производительность** проверена только в контейнере без видеокарты, с программным рендером. Там игра работает и все экраны открываются, но частоту кадров на настоящем железе я не измерял. В сцене около 300 вызовов отрисовки, для современных видеокарт это немного.
- **Звук** синтезируется, ошибок при воспроизведении нет. Послушать его в контейнере я не мог, поэтому громкость и тембр стоит подстроить по вкусу в настройках.
- **ИИ соперников** ездит по заранее рассчитанной траектории. На паре участков он иногда теряет несколько секунд или застревает, после чего возвращается на трассу автоматически.
- **Качество текстур** из настроек применяется после перезапуска. Тени и дальность прорисовки меняются сразу.
- **Сетевой игры** и настоящих drivatar-профилей нет: машины в свободной езде управляются тем же ИИ.
